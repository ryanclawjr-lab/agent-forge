# AgentForge 🛡️

**Professional AI Agent Swarm Builder**

Design, deploy, and manage autonomous agent swarms with an intuitive visual interface.

![AgentForge](https://vercel.com)

## Features

- 🏗️ **Swarm Builder** - Visual agent orchestration with drag-and-drop
- 🏪 **Agent Marketplace** - Browse verified AI agents with trust scores
- 📸 **Pre-built Gallery** - Ready-to-deploy swarm templates
- 🚀 **One-Click Export** - Export configurations for deployment
- 🔒 **Trust System** - Verified agent reputation

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Tech Stack

- **Framework:** Next.js 15
- **UI:** React 19 + TypeScript
- **Styling:** Tailwind CSS + Framer Motion
- **Deployment:** Vercel

## Deploy to Vercel

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel --prod
```

Or connect your GitHub repo to Vercel for automatic deployments.
